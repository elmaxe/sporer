# Spore 2: space stage

Browser game in Three.js inspired by Spore's space stage. Stack: Vite + TypeScript (strict), three, Rapier (`@dimforge/rapier3d-compat`), lil-gui + stats.js (debug), Vitest.

## Commands

- `npm run dev`: dev server on http://localhost:5173 (debug panel on)
- `npm run typecheck` / `npm test` / `npm run build` / `npm run preview`
- `npm run smoke`: headless browser check (needs the dev server running): loads the game, checks the ship hovers above the star with no manual flying, checks the system map, the stars and comets are alive, hovers and clicks an asteroid belt, runs the galaxy and planet loops, enters a system inside each kind of nebula, flies to a rogue planet and down to it (every planet type, geyser kind and weather kind, `-- --quick` for just the home system; every zoom between levels must crossfade and never go black), grows every plant architecture at every level of detail in the plant lab, plays with touch on an emulated phone, raises a volcano with the volcano bomb, fires the planet buster at a moon (last), reports FPS and console errors plus screenshots. `-- --only <sections>` runs just some (`core,galaxy,nebulas,rogues,audio,planet,types,lab,plants,touch,volcano,buster`; use this while working, the full run before pushing); it renders at `?quality=low` unless `--full-quality`, prints each section's time as it goes, and fails fast (naming the step) if the page stalls
- `npm run shot -- --out <dir> --clean <steps...>`: screenshots of the running game after scripted steps (see the `screenshot` skill); `--lab` shoots the planet lab instead, `--plants` the plant lab
- `npm run dump -- <file.json>`: unpacks a debug dump (the game menu's Save debug dump button, or F8: the screen, the player's marks and note, game state, device, GPU, frame times, console errors, in one JSON file) into pictures and a summary; `npm run shot -- --dump <file.json>` restores its state in the headless browser (see the `debug-dump` skill)
- Planet lab: http://localhost:5173/lab.html (deployed at https://elmaxe.github.io/sporer/lab.html). One planet or moon drawn by the game's own code, every property editable in the panel (type, size, colours, sea, relief, gas bands, atmosphere, climate and the weather it brings, rings, moons, a comet's or asteroid's shape, a comet's activity, light, time), in low orbit or the system view. Use it to look at, debug and test planet features: `?gen=<seed>&type=<type>&kind=<size class, moon, comet or asteroid>` makes one, `?seed=<galaxy>&star=<id>&planet=<i>[&moon=<j>]` loads a game planet (`&comet=<k>` instead of `planet` a comet, `&belt=<b>&asteroid=<k>` a named asteroid), the `#hash` is the exact planet (the page keeps it updated; the game's menu (Esc, or the menu button on phones) and low orbit's debug panel open the current planet in it; it works on phones too), and `window.lab` drives it (`lab.set`, `generate`, `load`, `loadComet`, `loadAsteroid`, `look`, `lookAtVent`, `lookAtStorm`, `setTime`, `ready`)
- Plant lab: http://localhost:5173/plants.html (deployed at https://elmaxe.github.io/sporer/plants.html). Plant species grown by the game's own generator (`gen/plantForm.ts`: conifers, broadleaves, palms, shrubs) and drawn with its own meshes and materials (`surface/plantMesh.ts`, `plantLook.ts`). Every species property is editable in the panel: envelope, branching, leaves, colours. Views: one plant (zoom out through the game's level-of-detail crossfade), the levels side by side, or a grove planted by the game's `SurfaceEntities`; the levels can be tinted. `?gen=<seed>&tier=<1-3>&kind=<kind>&arch=<architecture>` makes a set, `?seed=<galaxy>&star=<id>&planet=<i>[&species=<j>]` loads a game planet's plants, and the `#hash` is the exact set. The planet lab's Plants link opens its planet's species. `window.plantLab` drives it (`set`, `setForm`, `select`, `setArchitecture`, `generate`, `load`, `setView`, `look`, `ready`)
- Deploy: GitHub Actions (`.github/workflows/deploy.yml`) runs typecheck/test/build and publishes each version to its own folder of GitHub Pages (kept on the `gh-pages` branch by `scripts/pages-publish.sh`, listed in its `versions.json`): a `v*` tag (a GitHub Release) to https://elmaxe.github.io/sporer/, `main` to https://elmaxe.github.io/sporer/preview/, each open pull request to https://elmaxe.github.io/sporer/pr/<n>/ (linked from a comment on it, removed when it's closed). The game menu's Version picker switches between them (`src/ui/versions.ts`), and an installed app opens the one picked
- URL params: `?seed=<number or text>` picks the galaxy (default 1337), `?star=<id>` starts in that system (ids after the stars' are the rogue planets; default: generated home system; the URL follows you as you change systems), `?debug` enables the debug panel in production builds, `?quality=low` renders at half resolution without antialiasing (about 5× faster under software WebGL; the smoke test uses it)

## Skills

- `threejs-game-conventions`: architecture, Entity lifecycle, physics/perf rules. Read before writing game code.
- `run-game`: start the server and verify in Chrome. Use after changes.
- `screenshot`: take in-game screenshots with `npm run shot` whenever something needs checking by eye (the planet lab with `--lab`: the quickest way to see a planet feature on any kind of body; the plant lab with `--plants` for plants and their levels of detail).
- `debug-dump`: read a debug dump file the player saved (sporer-dump-*.json) and reproduce it. Use whenever one is shared.
- `research`: researching anything real-world (climate, atmospheres, physics, techniques): look it up, measure it against reference cases, record it in `docs/research/`. Never guess numbers.
